1.8.0 更新

用一句话，找回那一页

升级后首次打开扩展即可浏览更新亮点，之后也能在「关于 → 本次更新亮点」重看。

本机语义搜索

用日常语言从标签页、收藏夹和最近一万条历史记录中找回页面。模型首次下载约 136 MB，匹配在本机完成。

设置 → 快捷搜索 → 语义搜索（本机）

网页内容索引与摘要

授权后，访问网页时在本机建立索引。快搜把应用名、模块等关键信息放在标题右侧，让同名标签也容易区分。

设置 → 快捷搜索 → 索引页面内容

多条件自动分组

组合标题、域名、网址、路径、参数或片段，按「任一满足」或「全部满足」匹配。规则可单独启停，修改后会重新匹配已打开的标签页。

分类设置

常规、快捷搜索、分组命名和自动关闭各有独立标签。弹窗和侧边栏使用同一套导航。

查找与整理标签页

从打开一个页面到管理多个窗口，把常用操作留在手边。

规则分组

按域名、正则或组合条件归类。自定分组名称和颜色，拖拽调整规则优先级。

跨窗口快捷搜索

一起查找打开的标签页、收藏夹和历史记录，用键盘选择结果。也可调用浏览器默认搜索引擎。

批量管理

在弹窗或侧边栏展开和折叠分组，关闭选中的标签页，找回刚关闭的页面。各窗口保留自己的分组。

闲置关闭与锁定

按需开启自动关闭并设置闲置时长。重要标签页或整个分组可加锁保留。

外观与语言

支持亮色、暗色和跟随系统。快捷搜索有经典和毛玻璃外观，界面支持简体中文和 English。

配置迁移

通过 JSON 文件导出分组规则和支持迁移的设置，再导入到另一台设备。

浏览数据留在本机

搜索、规则匹配和向量索引都在设备上完成。网页内容索引由你单独开启和授权。

阅读隐私政策
由你决定授权范围
可授权所有普通 HTTP(S) 网页，也可以通过链接或域名单独添加站点。
访问时索引，空闲时补采
访问授权页面时提取可见的关键信息。其他打开的标签页会在空闲时分批处理，摘要相同则复用已有向量。
可暂停、撤销或清空
撤销站点授权会清除该授权产生的摘要和向量。语义搜索设置也提供清空本机模型与索引的操作。

常见问题

快捷键、索引设置和浏览器兼容性。

问题反馈
怎么打开快捷搜索？

macOS 默认按 ⌘ + ⇧ + K，Windows 和 Linux 默认按 Alt + Shift + K。也可以从侧边栏打开，实际绑定见「设置 → 快捷搜索」。

怎么让搜索结果显示网页摘要？

在「设置 → 快捷搜索」开启本机语义搜索和「索引页面内容」，选择授权范围，再访问要索引的网页。

Microsoft Edge 可以安装吗？

可以。用 Edge 打开 Chrome 应用商店中的 TabAssistant，按浏览器提示允许从其他商店安装扩展。

可以把规则带到另一台电脑吗？

可以，在「设置」中用 JSON 导出规则和设置，再到另一台设备导入。语义索引在每台设备上单独建立。
