搜索与规则在本机运行

你可以独立选择是否启用 AI 分组和网页内容采集。

  • 本地匹配

    标签页、收藏夹和历史记录的检索，以及基于规则的分组，都在浏览器本机完成。

  • AI 请求直连所选服务商

    开启 AI 后，相关标签标题、网址、分组信息和单独授权采集的内容可能随请求发送给所选服务商。API 使用可能计费。

常见问题

快捷键、兼容性和 AI 的使用方式。

前往 GitHub 反馈
怎么打开快捷搜索？

默认快捷键为 macOS 上的 ⌘ + ⇧ + K，以及 Windows / Linux 上的 Alt + Shift + K。实际绑定可在扩展设置的「快捷搜索」中查看，也能从侧边栏打开。

可以用 Microsoft Edge 安装吗？

可以。从 Chrome 应用商店打开扩展详情，在 Edge 中根据提示允许从其他商店安装扩展。

使用扩展需要配置 AI 吗？

域名或正则分组、快捷搜索和标签管理都可以直接使用。需要按任务分组时，再到「规则」中切换到 AI 模式并配置服务商。

可以把规则带到另一台电脑吗？

可以。在「设置」中导出 JSON，再从另一台电脑导入。导出会包括分组规则和支持迁移的设置，API Key 保存在原设备上。
